# ChainRace

PCブラウザで遊ぶ協力パルクール。ホストが公開・招待限定の部屋を作り、参加者と同じコースで遊びます。固定の大部屋は使いません。

夕暮れの自然と紺色のプレートを背景に、ハンマー＋フックを基本装備として、自転車・中華まん・幽霊に持ち替えます。コースエディタは3列のパーツ選択、説明一覧、DD系ギミック、JSON入出力、即時テストに対応。顔エディタで描いた絵には目が付きます。

操作・部屋・公開手順は[ROOMS.md](ROOMS.md)、参照元ライセンスは[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照。

## 開発

```
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

`VITE_LOCAL_ONLY=1`でFirebaseを使わないローカルテストに切り替わります。本番公開の前に同梱のFirestoreルールとインデックスを適用してください。

## コース

旧収録コースは公開版の選択肢から外しました。ログインした作者がプレリリースしたコース、またはホストが読み込んだコースで遊べます。新作コースは作者のファイル受領後に追加します。旧マップは物理の回帰検証用に保持しています。

### コース用のシンプルな美術
通常の凍結・解凍は半透明の薄青・薄黄色、フック透過壁は茶色の網目、通常転送入口は黒、出口は半透明の黒い渦巻きです。肉まん・自転車・人魂の配置画像は `client/public/art/original/` に保存。DDNetの編集用画像は配布対象から外しました。その他のパーツは仮デザインのままです。


### ダミー切り替え時の長押し
DDNetの「切り替え時に入力をリセットしない」動作に合わせ、切り替え前の移動・ジャンプ・フック・攻撃と照準を操作対象ごとに保持します。切り替え先でボタンを離しても元のキャラクターの保持は続きます。元へ戻して同じ操作を押して離すと解除できます。ダミー削除時には保持状態をリセットします。単発の自殺・中華生成・消去・武器切替は保持しません。同時操作・自動ハンマーを有効にした場合は、それぞれの設定が優先します。
参考：DDNet `src/game/client/gameclient.cpp` の `OnDummySwap` / `OnSnapInput` と `src/game/client/components/controls.cpp` の入力管理。

## 再読み込みからの復帰
同じタブのsessionStorageへホストの世界状態を約1秒ごととpagehide/非表示時に保存します。再読み込み時は同じ部屋へ自動接続し、参加者は秘密の再接続トークンで元のIDを引き継ぎます。ホスト復帰は同じhostIdとFirebase UIDで検証します。参加者が切断した場合は最大2分間世界と計時を止め、位置・ダミー・仕掛けを保持します。押しっぱなしの入力は解除します。明示的な退室は保存を消します。保存は24時間で自動復元の対象外になり、別タブ・別端末・エディタのテストプレイは対象外です。保存容量不足は画面に通知します。
