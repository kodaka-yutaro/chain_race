# KDレース 中華街 パルクール大会

フックでつながる、ブラウザで遊べるオンライン協力2Dアクション。

## 遊び方

| 操作 | キー |
| --- | --- |
| 移動 | A / D |
| ジャンプ | Space（空中でもう一度押すと二段ジャンプ） |
| フック | 右クリック長押し または E（岩壁に掛けると引き寄せられる。仲間にも掛かる。金属には掛からない） |
| ハンマー | 左クリック または Q（近くの仲間を叩いて飛ばし、しびれを解く） |
| 大中華を吐く / 消す | R / X（スマホは「大中華」「大を消す」） |
| ミニ中華を吐く | T（スマホは「ミニ中華」） |
| スタート地点へリスポーン | Esc / K（メニュー・文字入力中は除く） |
| 大部屋へ戻る | 画面の「大部屋へ戻る」ボタン |

DDNet（DDRace）の操作を参考にした独自の物理です。スマホは左スティックで移動、右スティックで照準とフック、専用ボタンでジャンプ・攻撃を行います。

- 名前だけ入れてゲストで遊ぶか、アカウントを作ってクリアタイムをランキングに残せる。
- 入るとまず「大部屋」（最大16人）を選ぶか作る。大部屋はキャラで歩き回れる広場で、チャットは頭上に吹き出しでも出る（Enter で入力）。
  - 左の **フリー入口** で F: そのステージの、誰でも途中参加できるセッションに入る。
  - 右の **協力の台** で F: 3秒のカウントのあと、台に乗っている全員（最大8人）がパーティとして出発する。抜けるなら台から降りる。
  - ステージで Esc を押すと、コースを抜けずにスタート地点へ戻る。広場へは画面の「大部屋へ戻る」ボタンから戻れる。

### ステージ

**中華吐息の稽古場**では「中華」を吐き出す新しい技を試せます。大部屋の「コース一覧」から直接参加できます。

1. **はじまりの丘**: 操作の練習。1人でクリアできる。
2. **しびれ洞窟**: フックで支点をたどる回廊と、フックで登る煙突。
3. **ツナグの塔**: 2人以上が必要。スイッチ扉、ハンマーでの打ち上げ、フックでの引き上げ。

### タイル

`#` 岩壁（フックが掛かる） / `X` 金属壁（掛からない） / `~` しびれ床 / `^` トゲ / `J` バネ /
`S` スポーン / `>` スタート線 / `F` ゴール線 / `1`〜`4` スイッチ / `a`〜`d` 扉（`1` で `a` が開く）

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # 物理・ステージ・大部屋の進行のテスト
npm run typecheck
```

`client/net/firebase-config.ts` が `null` のままだと、Firebase を使わず **同じブラウザのタブ同士だけ** でつながる動作になる（開発・確認用）。タブを2つ開けば2人で試せる。

## 構成

サーバーを持たない。GitHub Pages に置いた静的なページだけで動く。

- **ゲームの進行**: 大部屋を作った人（主）のブラウザが、その大部屋の全員の物理を計算して配る（`client/host/`）。参加者とは WebRTC で直接つながる（`client/net/rtc.ts`）。主のタブが裏に回っても止まらないよう、Worker のタイマーで進める。
- **Firebase（無料の Spark プラン）**: アカウント（Authentication）、大部屋の一覧と接続の仲介、自己ベストとランキング（Cloud Firestore）。ルールは `firestore.rules`。
- `shared/physics.ts` 決定的な物理（50 tick/秒）。主と参加者で同じコードを使い、自分のキャラは予測して主の状態で補正する。
- `shared/maps.ts` ステージ定義（四角形を重ねて組み立てる）。

制約:
- 主が大部屋を出ると、その大部屋は閉じて全員が一覧に戻る。
- 主の回線で全員分を送るので、大部屋は16人まで。
- 記録は各プレイヤーのブラウザが保存するので、改造すればズルはできる（協力ゲームなので許容）。
- 会社や学校のネットワークなど一部の環境では直接つながらない。困ったら TURN サーバーを用意して `VITE_TURN_*` を設定する。

## 公開（https://chainrace.kdking-tools.com）

### 1. Firebase を用意する（初回だけ）

1. https://console.firebase.google.com で「プロジェクトを作成」（名前は `chainrace` など。Google アナリティクスはオフでよい）。
2. 「構築 → Authentication → 始める」で、ログイン方法の **メール / パスワード** と **匿名** を有効にする。
3. 「構築 → Firestore Database → データベースを作成」。場所は `asia-northeast1`（東京）、「本番環境モード」で作る。
4. Firestore の「ルール」タブに `firestore.rules` の中身を貼って「公開」。
5. 「Authentication → 設定 → 承認済みドメイン」に `chainrace.kdking-tools.com` を追加。
6. 「プロジェクトの設定（歯車）→ マイアプリ → ウェブ（`</>`）」でアプリを登録し、表示される `firebaseConfig` を `client/net/firebase-config.ts` に貼る。

### 2. GitHub Pages

1. リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にする。
2. main に入るたびに `.github/workflows/pages.yml` がテスト・ビルドして公開する。
3. Settings → Pages → Custom domain に `chainrace.kdking-tools.com` を入れ、Enforce HTTPS をオンにする（`client/public/CNAME` にも書いてある）。

## コース工房・プレリリース

「中華」を吐き出す技は、工房のチェックボックスでコースごとに有効にできます。大中華は約0.36秒の溜めから赤と金の文字が現れ、文字の線だけが動く足場になります。乗って運ばれる・フックを掛ける・仲間と同じ文字を使うことができ、壁や人に重なる場所では出ません。再使用は6秒、一人1個まで。時間では消えず、持ち主が X /「大を消す」で消します。狙った向きに飛び、壁で跳ね返ります。

ミニ中華は T /「ミニ中華」で出す32pxの箱です。個数制限はなく、重力で落ちて地面や箱の上に積めます。フックで箱を手元へ引けます。出し直しの間隔は0.24秒で、長押しでは連射しません。大・ミニとも持ち主がコースから退出すると片付きます。通常コース・DDNet移植コース・大部屋で標準使用できます。自作コースは工房の設定で有効・無効を選べます。

大部屋一覧の「コースをつくる」でタイルを配置できます。下書きは端末に自動保存され、JSONで持ち運べます。投稿にはログインが必要です。テストクリアなしで投稿でき、同じ大部屋の「コース一覧」から同じコースに参加します。2人揃うまで操作を受け付けません。全員がゴールすると正式公開になり、初クリアの名前とタイムが残ります。途中離脱で人数が減った場合は正式公開しません。編集版は新しいIDで投稿し、古いクリアを引き継ぎません。

**導入時は `firestore.rules` をFirebaseコンソールへ反映する必要があります。** 既存ルールのままではコース一覧・投稿・正式公開の保存は権限エラーになります。既存のアカウント・大部屋・記録用ルールは変更していません。

公開の判定は既存のタイム保存と同じブラウザ信頼モデルです。通常の画面操作ではホストが確認した全員ゴールに限定しますが、改造クライアントに対するサーバー上のリプレイ検証はありません。

### DDNet移植の現状

- Sunny Side Up / Ravie: 公式 `.map` のゲームレイヤー1200×200をそのまま変換。岩壁、金属、しびれ、しびれ解除、フック透過壁75マス、出現地点、スタート、ゴールに対応。全画面分の巨大画像を作らず、16×16タイル単位で描画。DDNetの美術・音楽は移植していません。現在の物理エンジンでの通しクリアは未検証です。
- Kobra / Zerodin: 公式配置900×897を変換。ゲーム・フロント・テレポート・加速・スイッチの各レイヤーを保持し、番号ごとの出口、フック転送、ソロ、方向別ストッパー、32本のスイッチ扉、ジャンプ数、無限ジャンプ・フック、ジェットパック、武器の取得と解除に対応しました。銃・散弾の牽引・グレネードの爆風・レーザーの解凍・忍者のダッシュはKDエンジンの実装です。本家の物理と完全互換ではなく、全区間の通しクリアは未検証の移植プレリリースです。
- 原本: `client/public/ddnet/`。出典: https://ddnet.org/maps/Sunny-32-Side-32-Up 、 https://ddnet.org/maps/Kobra 。元作者のクレジットを保持してください。

スマホでは左スティックで移動、右スティックで照準とフック（離すと解除）、中央にジャンプ・ハンマーを配置。直接画面を触るフックも引き続き使えます。

Kobraでは数字1〜6または画面の武器ボタンで選択します。スマホは右スティックを「照準だけ」に切り替え、狙いを固定して攻撃できます。大部屋の「コース一覧」には大会コースへ直接入るボタンもあり、同じ大部屋で同じコースを選ぶと合流します。

## 中華街大会の公開設定

タイトルは丸いはちまきキャラを中心に、屋台・寺院・獅子舞・街の住人を描いた専用イラストにしました。縦画面には別構図を読み込み、「大会に参加する」から名前入力を開きます。イラストは本作向けに画像生成で制作し、配信用にはWebPを使用しています。

ゲーム内は点心横丁・福慶寺広場・灯火縁日の3街区が続き、カメラに合わせて遠景・街並み・提灯が別々の速度で流れます。19人の住人は個別の姿・持ち物・4コマ動作を持ちます。建物と人物は初回描画を再利用し、毎フレームの負担を抑えています。背景の住人や屋台は演出で、コースの物理判定は変わりません。

URLを知っている仲間が参加する非掲載ページです。検索対象から外すnoindexを各ページに設定し、サイトマップは空にしています。これはパスワード認証ではありません。BGMと背景はこのプロジェクトのオリジナルで、音楽はユーザーの操作後にのみ再生し、別タブでは停止します。左スティックの上端でジャンプする補助は、プレイ画面でON/OFFを切り替えられます。
