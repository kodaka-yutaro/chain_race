# ツナグラン

ワイヤーでつながる、ブラウザで遊べるオンライン協力2Dアクション。

## 遊び方

| 操作 | キー |
| --- | --- |
| 移動 | A / D |
| ジャンプ | Space（空中ではマウス方向へダッシュ1回、岩壁に触れていれば壁キック） |
| ワイヤー | 右クリック長押し または E（岩壁と仲間に刺さる。金属には刺さらない） |
| 巻き取り / 繰り出し | W / S |
| エアキャノン | 左クリック または Q（仲間を吹き飛ばし、しびれを解く） |
| やり直し | K |
| 大部屋へ戻る | Esc |

- 名前だけ入れてゲストで遊ぶか、アカウントを作ってクリアタイムをランキングに残せる。
- 入るとまず「大部屋」（最大32人）を選ぶか作る。中で「仲間と遊ぶ」（パーティ最大8人、リーダーが開始）か、「フリーで遊ぶ」（誰でも途中参加）を選ぶ。

### ステージ

1. **はじまりの丘**: 操作の練習。1人でクリアできる。
2. **しびれ洞窟**: ワイヤーの回廊と壁キックの煙突。
3. **ツナグの塔**: 2人以上が必要。スイッチ扉、エアキャノンでの打ち上げ、ワイヤーでの引き上げ。

### タイル

`#` 岩壁（ワイヤー・壁キック可） / `X` 金属壁（どちらも不可） / `~` しびれ床 / `^` トゲ / `J` バネ /
`S` スポーン / `>` スタート線 / `F` ゴール線 / `1`〜`4` スイッチ / `a`〜`d` 扉（`1` で `a` が開く）

## 開発

Node.js 22.13 以上。

```sh
npm install
npm run dev        # サーバー :8080 と Vite :5173 を同時に起動 → http://localhost:5173
npm test           # 物理とステージのテスト（協力ルートが通れるか、1人で越えられないか）
npm run typecheck
```

## 構成

- `shared/physics.ts` 決定的な物理（50 tick/秒）。サーバーとクライアントで同じコードを使う。
- `shared/maps.ts` ステージ定義（四角形を重ねて組み立てる）。
- `server/` Node.js + WebSocket。物理はサーバーが正（不正なタイムを防ぐ）。SQLite（`node:sqlite`）にアカウントと記録を保存。
- `client/` Vite + TypeScript + Canvas。自分のキャラはクライアント予測し、サーバーの状態で補正する。

## 公開（https://chainrace.kodking-tools.com）

WebSocket を常時つなぐため、常駐サーバーが動く Render を使う。設定は `render.yaml` にある（Docker、Starter プラン、1GB ディスクに SQLite を置く）。

1. Render で「New > Blueprint」を選び、このリポジトリをつなぐ。`render.yaml` のとおりに `chainrace` サービスが作られる。
2. デプロイが終わったら、サービスの「Settings > Custom Domains」に `chainrace.kodking-tools.com` が入っていることを確認する。
3. ドメインを買ったサービスの DNS 設定で、次のレコードを追加する。

   | 種類 | 名前（ホスト） | 値 |
   | --- | --- | --- |
   | CNAME | `chainrace` | `chainrace.onrender.com`（Render の画面に出る `xxx.onrender.com` を使う） |

4. Render の Custom Domains で「Verify」を押す。証明書（HTTPS）は自動で発行される。

## 広告

- 広告はプレイ中には出さず、タイトル・ロビー・リザルトにだけ出す。
- AdSense の審査には独自ドメインと、`/about.html`・`/privacy.html` のようなページが必要。`privacy.html` の運営者名と連絡先を記入する。
- 審査通過後、`.env.example` の値をビルド時の環境変数に設定し、`client/public/ads.txt` を置く。
